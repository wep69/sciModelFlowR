# Reference verification status

Version 0.1.0 methodological vignettes intentionally avoid a large formal bibliography while the package architecture is being validated. No unverified DOI metadata are asserted in the distributed teaching text. Method-specific references will be added with a machine-readable verification ledger as the corresponding engines are implemented.

The package specification and development records are not themselves empirical evidence. Future software-paper and state-of-the-art documentation must verify bibliographic metadata against at least two sources when practical.
