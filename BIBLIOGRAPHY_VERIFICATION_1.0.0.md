# sciModelFlowR 1.0.0 Bibliography Verification Status

The current package teaching material intentionally avoids asserting unverified DOI metadata. The machine-readable ledger is `inst/metadata/BIBLIOGRAPHY_LEDGER_1.0.0.csv`. At initialization of 1.0.0, no package release claim depends on an unverified DOI citation.

A software-paper or state-of-the-art manuscript requires a separate bibliographic verification campaign, ideally checking each bibliographic record against at least two independent authoritative sources when practical. That manuscript-level task is distinct from package runtime certification and remains pending.
