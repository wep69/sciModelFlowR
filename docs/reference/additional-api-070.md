# Additional workflow, resampling, probabilistic, and explainability interfaces

Grouped documentation aliases for public interfaces introduced in the
staged 0.1.0–0.7.0 implementation series. Detailed scientific usage,
assumptions, failure modes, and complete examples are provided in the
versioned vignettes.

## Details

These functions participate in design-aware preprocessing, resampling,
bootstrap, feature engineering, supervised/probabilistic modeling,
calibration, imbalance handling, explanation, diagnostics, and
reporting. Managed operations preserve the package's training/assessment
boundaries. Runtime and numerical certification for the complete staged
release remains deferred to the consolidated local validation campaign.

## Value

Function-specific package-native specification, result, table,
prediction, diagnostic, or plotting objects.
