# sciModelFlowR 0.9.0 Release-Candidate API Freeze

The machine-readable export catalog is
`inst/metadata/API_FREEZE_0.9.0.csv`; its checksum is stored in
`inst/metadata/API_FREEZE_0.9.0.sha256`. The public export set is frozen
for the 1.0.0 transition.

Optional backend implementation does not equal release certification.
`inst/metadata/BACKEND_MATRIX_0.9.0.csv` records optional backends as
quarantined pending the consolidated local validation campaign.

The 1.0.0 release may change this API only to correct a blocker
discovered by validation, security review, installation checks,
numerical/reference tests, documentation execution, or release
engineering.
